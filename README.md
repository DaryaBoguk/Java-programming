Написаны программы на языке программирования Java, изучены различные инструменты и технологии языка:  
1. Изучены механизмы работы с файлами и потоками данных  
2. Рассмотрены свойства, используемые для конфигурации приложений, и их удобное управление.  
3. Регулярные выражения  
4. Изучена работа с сетевыми соединениями, включая создание клиент-серверных приложений, используя сокеты
